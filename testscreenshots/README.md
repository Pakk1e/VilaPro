# Worlds browser test screenshots

This directory is the output location for the Worlds DEV Playwright browser tests.

- Screenshots, traces, and videos generated by CI are uploaded as GitHub Actions artifacts.
- Generated files are intentionally ignored by Git so test runs do not pollute the repository.
- Approved visual baselines can be introduced later under a dedicated Playwright snapshot directory and reviewed as normal Git changes.

The initial browser suite is intentionally a smoke suite. It covers the login page, registration navigation, and unauthenticated protection of the Worlds route. Authenticated workspace/schematic/simulation flows will be added as those UI flows stabilize.
